# Richiesta dati GeoZone Italia — bozza da inviare a ENAC

**Destinatario:** mobilita.innovativa@enac.gov.it (contatto ENAC per zone geografiche UAS: https://www.enac.gov.it/sicurezza-aerea/droni/contatti/)

**Oggetto:** Richiesta disponibilità e riutilizzo dati geografici UAS nazionali — progetto Drone Italia

Gentile Direzione,

sto sviluppando Drone Italia, un'applicazione gratuita per la consultazione informativa di dati utili ai piloti UAS. Vorrei integrare un livello cartografico nazionale delle zone geografiche UAS, mantenendo il riferimento alla verifica operativa ufficiale su d-flight.

Vi chiedo cortesemente:

1. Se sia disponibile un dataset nazionale delle zone geografiche UAS in formato GeoJSON, JSON ED-269 o altro formato geografico aperto, consultabile e scaricabile gratuitamente.
2. Quali siano le condizioni di licenza, attribuzione e **redistribuzione** dei dati in un'app gratuita e in un repository GitHub pubblico.
3. Se siano disponibili URL stabili, API o modalità di aggiornamento periodico, con indicazione di frequenza, data di validità e gestione delle zone temporanee.
4. Se occorra una specifica autorizzazione o un accordo con ENAC, ENAV o d-flight per questo uso.
5. Quale ufficio o referente sia competente per il rilascio o il riutilizzo di tali dati.

Non intendo ripubblicare mappe o dati soggetti a limitazioni contrattuali senza autorizzazione. Il progetto distinguerà sempre dati informativi e verifica ufficiale prima del volo.
